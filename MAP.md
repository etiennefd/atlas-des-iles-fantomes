# Map checklist — placement and shape

Where each island sits on the globe and what shape it is drawn as. This is
**not** the story checklist: an island can have a finished story and still be
a placeholder blob in the wrong place, and several are.

A box is ticked when the island has a **traced outline from a named
depiction**. Everything else is a `blob` — a generated placeholder, which for
some islands is the honest answer and for others is simply undone.
Position confidence is shown alongside; the reasoning lives in
[COORDINATES.md](COORDINATES.md), and `outline_note` in each island's YAML
records which depiction a shape came from.

Check a placement with `node scripts/check_overlap.mjs <id>` — the map cannot
show you an island lying on real land.

Stories that cover more than one island are split here, because placement and
shape are per-island: Crocker Land and Bradley Land, Juan de Lisboa and Dos
Romeiros, and the reefs each appear separately.
